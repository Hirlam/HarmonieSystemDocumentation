IRS radiance assimilation

This page contains information regarding the assimilation of observations from the InfraRed Sounder (IRS) instrument onboard of the Meteosat Third Generation (MTG) geostationary satellite in HARMONIE.

Introduction/Background

IRS is the first instrument that provides a continuous coverage of the hyperspectral infrared spectrum over Europe. This is of particular interest to NWP-centres using regional models over Europe. Pre-operational data of this satellite has been available as of the end of May 2026.

The spectrum is measured in 877 longwave (LW)IR channels (8.26 to 14.7 micrometer) and 1076 mediumwave (MW)IR channels (4.44 to 6.25 micrometer). Temperature and window sounding channels are present in the LWIR band, whereas the MWIR band predomoninantly consists of water vapour sounding bands. The ozone sounding band (around 9.6 micrometer) also lies within the LWIR band. For more info, see

The instrument has a spatial resolution of approximately 4 km at nadir. The scanning sequence of the Earth disk is divided into 4 quarters, called LACs. The northern most LAC containing Europe is thereby scanned every 30 minutes, for 15 minutes per LAC. In between the other 3 LAC areas are scanned. Hence, the sequence goes:<br> &ensp; LAC4 &#8594; LAC3 &#8594; LAC4 &#8594; LAC2 &#8594; LAC4 &#8594; LAC1 &#8594; LAC4 &#8594; LAC3 &#8594; ... <br> Each LAC consists of several dwells. The total number of dwells are season dependent to maintain full coverage of the disk. The detector has 480x480 pixels and uses groups of 3x3 (super-pixels) to obtain 160x160 interferograms per band.

The data is in near real time distributed via PC-scores to compress the data volume. As of now, these need to be reconstructed into full spectrum radiances before they can be assimilated. This can be done with the NWP SAF IRSPP software. The spectral radiances in [W/m2/sr/m-1] are available via EUMETSAT's data store. For more info on either data format, see IRS PC-scores and IRS spectral soundings

For more information on IRS, the reader is directed to EUMETSAT's data guide.

Converting IRS PC-scores to radiances

The IRS observations are distributed in near-real time with the 300 leading principal component scores. This data can be reconstructed into radiances using the eigenvector basis and the NWP SAF IRSPP software. With the IRSPP software, users can:

  • Define a(n initial) channel selection.
  • Perform data thinning by selecting 1 spot in n spots or 1 line in m lines;
  • Apply Hamming apodisation vs "light apodisation". It is recommended to use Hamming apodisation as RTTOV does not work well with lightly-apodised radiation due to the negative sidelobs of the spectral response function. See section 3.2 of the IRSPP User Manual (V1.6);
  • Generate the BUFR file with IRS radiances. See chapter 9 of the IRSPP User Manual (V1.6) for the exact BUFR sequence;
  • Do several other things, such as generating PC-scores, computing compression and reconstruction matrices and generate covariance matrices from spectral sounding sample products.

Including IRS radiances in a HARMONIE run

scr/include.ass

scr/include.ass should be edited to "switch on" the use of IRS:

export IRS_OBS=0               # IRS
export IRS_SOURCE=ears         # mars:MARS | else: file in $OBDIR
[[  $IRS_OBS -eq 1  ]] && types_BASE="$types_BASE irs"

IRS namelists

Channel selection

The channel selection namelist can be found at nam/irschannels. Note that channel selection/filtering is also done through Bator (scr/Bator) and the blacklist (src/blacklist/hirlam_blacklist.b.monthly_after_20140601).

Cloud detection

The cloud detection namelist is nam/IRS_CLDDET.NL.

Loading the IRS radiances

Below is the code linking the BUFR file for Bator (scr/Bator):

      elif [ "$base" = irs ] ; then
        # IRS
        if [ "$IRS_OBS" -eq 1 ]; then 
          echo "irs      irs      BUFR     irs      ">>batormap
          ln -sf "${HM_LIB}"/const/bator_param/param_bator.cfg.irs param.cfg
          if [ "$IRS_SOURCE" = mars ] ; then 
            ln -sf "$WRK"/splitObs/irs ./BUFR.irs
          else
            ln -sf $OBDIR/irs$DTG ./BUFR.irs
          fi
        fi

Controlling the detection of clouds

Just like the IASI observations, IRS radiances are strongly influenced by clouds. Because of inaccurate forward modelling, large background errors in cloud fields, and non-linear effects, success in the use of IRS will require careful screening and removal of cloud-affected data. In the HARMONIE data assimilation system, the screening for cloud follows the method of McNally and Watts (2003). The power of this method lies in the use of a large number of individual channels such that much of the disturbing instrument noise can be smoothed out and the cloud radiative effect is therefore more easily detected.

Even if the active use of IRS is limited to a relatively small number of channels, it is advisable to include more than 100 channels in the cloud detection channel list. Furthermore, it is important that all these channels are subjected to VarBC. To achieve the latter, one needs to make sure that blacklisting for the cloud detection channels uses the fail(EXPERIMENTAL) syntax rather than fail(CONSTANT).
